## 一、审核结论（按严重度）

### 🔴 P0 — 流程断点：竖屏跟读「读完了」被底部 tab 完全盖住

**证据**：`08_shadow_portrait.png`；实测 390×844 下 `[data-act=tostage]` 的 y=757–791，`nav.tabs` y=756–844 → 完全重叠。`.shadow-wrap` 底部 901px 已超出视口 844px（body 高 1009）。

**后果**：孩子跟读完**找不到出口**，只能退出重进。这是全流程最严重的一处。

**建议**：竖屏跟读也照稿屏4 做「7 行窗口 + 透明底 + 播放条/工具条贴底」，并给 `.shadow-wrap` 清掉 `padding-bottom:96px`（该 padding 是给底部 tab 预留，但内容区没有把它算进滚动容器）。横屏已按稿屏3 修好（land-shadow），竖屏照同法处理即可。

### 🟠 P1 — 学习完成卡顶栏重复

**证据**：`10_study_done.png`；实测 2 个「本课完成」标题、2 个返回课程链接（外层 `renderLesson` topbar + 内层 `studyDoneCard` 的 `.khead2`）。

**建议**：完成卡走独立外壳，只保留一层顶栏（「本课完成 ｜ ‹ 退出」），去掉 stepper 与内层 khead2；与稿屏6「本课完成」单顶栏一致。

### 🟠 P1 — 复习跟读焦点错位

**证据**：`14_review_shadow.png`；全部 16 行虚化，焦点停在最后一句 `'This is a private conversation!'`，且看不到工具条（同 P0 遮挡）。复习模式没有走 w indow 化，也没有把焦点行滚到中部。

**建议**：复习跟读复用首学跟读的窗口/贴底逻辑；进入时按 `p.si` 定位并滚到中部。

### 🟡 P2 — 平板书：手机布局直接拉伸，没有平板版式

**证据**：`23–26_tablet_*.png`；820 宽下题干卡宽 792px，教材页挤成 10 列课格（每格约 70px、字极小），课文页下半屏整片空白。

**建议**：见第三节分档方案。

### 🟡 P2 — 其他小问题

- `20_me.png`：登录卡占首屏约 170px，统计环「1% 已学 / 0% 通关 / 29% 复习」语义不清（29% = 2/7 轮），近 7 天图全 0 仍占一屏。
- `19_player_more.png`：更多面板只露出一条「我的收藏 · 复选进队列 0 首」，被底部 tab 截住，形同虚设。
- `04_blind_quiz.png`：题干仍为完整式 `…to the people behind him?`，设计稿屏1 是简写 `Why did the writer complain?`（96 课数据都是完整式，未擅自改）。
- `17_listen.png`：6 个课本胶囊里只有 1 门 ready，其余 5 门「筹备中」，首屏信息量偏少但可接受。

## 三、平板端方案（用 M3E Canvas 出稿）

### 3.1 为什么用 M3E Canvas

本地应用：`E:\04 少儿原版课程\03 Think 0 课程制作\Codex 学习中心\M3E Canvas`（Next.js 16 / React 19，README.zh.md 明确用途：**浏览器里拼 Material 3 Expressive 屏幕 → 连流程点击试用 → 复制提示词给 AI 编程工具**）。全浏览器运行、无需账号，有手机与桌面两种画布、屏幕间连线跳转、主题一处调整。

**它的定位是「设计稿 → 提示词」，不是直接改我们的 HTML/CSS**。所以用法是：在 M3E Canvas 里把平板版式拼成可点击的屏幕流程，截图给你审；审通过后导出提示词，把版式落到 ily-echo 的实际代码里。

### 3.2 平板分档（建议三档，不按设备名分）

| 档 | 宽度 | 版式要点 |
|---|---|---|
| 手机竖屏 | ≤600 | 现状 + M1–M4 修复；单列，底部五 tab |
| 手机横屏 | ≤900 且高≤520 | 稿屏3：顶栏「跟读·全篇」、无四段条、5 行窗口、播放/工具条贴底、无底 tab（已实现） |
| 平板竖屏 | 601–1024 | **新增**：内容居中最大 720px（题干行长不超过 32–35 字符/行）；教材页课格 6 列（不是 10 列）；底部 tab 保留但缩到 64px；课文页四段条 + 内容区左右分栏留白均衡；不简单拉伸 |
| 平板横屏 | >1024 | 同平板竖屏的居中栏 + 左右辅助区（左侧课文/选项，右侧进度或译文），底部 tab 改侧边或保留 |

### 3.3 在 M3E Canvas 里的具体产出

1. **屏幕 1–4**：平板竖屏的「我的课程 / 教材页 / 盲听 / 跟读」，用 M3 Expressive 组件，画布设桌面尺寸并按 720px 内容宽排。
2. **流程连线**：我的课程 → 教材页 → 盲听 → 精听 → 跟读 → 完成卡，点击可走一遍（M3E Canvas 的 flow 功能）。
3. **主题**：沿用现有冷灰 + 品牌绿（`#F4F6F8` / `#0B8A5F` / `#10B981`），不引入 Material 默认紫。
4. **导出**：每屏提示词 + 整流程提示词，落到 `ily-echo/_ia_design/tablet/`。
5. **我给你看**：M3E Canvas 屏幕截图 + 流程走查图 + 导出的提示词全文，你审核通过后才动 ily-echo 代码。

### 3.4 不动的边界

- 16 句正文、60 天 OFFSETS、三段流程（删录音）、题目常驻、隐藏滚动条——均保持。
- 设计稿 v4.2 原稿不因平板方案改写；平板稿是新增一层。
- 不新增后端/账号依赖。
